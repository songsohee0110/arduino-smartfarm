# arduino-smartfarm

# 아두이노 스마트팜

고등학교 동아리 스마트팜 프로젝트입니다.

## 사용 부품
- Arduino UNO
- HC-06 블루투스 모듈
- 광저항 조도 센서
- MQ135 가스 센서
- 저항식 토양 수분 센서

## 핀 연결
- 토양 센서 AO: A0
- 조도 센서 분압점: A1
- 가스 센서 AO: A2
- HC-06 TXD: D10
- HC-06 RXD: D11에서 저항 분압 회로를 거쳐 연결
- 모든 GND 공통 연결

## 기능
- 토양·조도·가스 원시값 측정
- USB 시리얼과 블루투스로 데이터 전송
- 기본 30초마다 출력
- 마지막 출력값에서 100 이상 변하면 즉시 출력
- 출력할 때마다 30초 타이머 재시작

## 실행 방법
1. SmartFarm/SmartFarm.ino를 Arduino IDE에서 엽니다.
2. Arduino Uno와 연결된 포트를 선택해 업로드합니다.
3. 시리얼 모니터 속도를 9600 baud로 설정합니다.
4. 안드로이드 블루투스 터미널 앱에서 HC-06에 연결합니다.

## 참고
센서 값은 보정 전 원시값입니다.
토양 수분 퍼센트나 정확한 가스 농도를 뜻하지 않습니다.
가스 변화 알림은 안전·위험 판정 기능이 아닙니다.
